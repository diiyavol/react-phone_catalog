# 📱 React Phone Catalogue

> A modern React-based web application designed for cataloging, browsing, and searching for smartphones, featuring convenient filtering and detailed information for each model. 🛒✨
## 📋 Project Description

**React Phone Catalogue** is an interactive Single-Page Application (SPA) designed for easily selecting and exploring mobile devices. The project includes a product catalog with sorting and filtering options, a detailed product page for each phone, a shopping cart, and a responsive, intuitive user interface.

## 🛠️ Technical Requirements
To run this project on your computer, you will need:
* **Node.js** (version 20.x or later) — a JavaScript runtime environment.
* **NPM** (version 11.x or later) — a package manager for handling dependencies.

## 💻 Installation and Setup

Follow these steps to install the project and run it locally:

1. **Clone the repository:**
```bash
git clone [https://github.com/diiyavol/react-phone-catalogue.git](https://github.com/diiyavol/react-phone-catalogue.git)
```
2. **Navigate to the project directory:**
```bash
cd react-phone-catalogue
```
3. **Install dependencies:**
```bash
npm install
```
4. **Start the local development server:**
```bash
npm start
```

## 🌐 Usage
Once the project is running, it will be automatically accessible at http://localhost:3000 (or http://localhost:8080, depending on your configuration). You can use this URL to browse the catalog, test the shopping cart, and verify the responsive design. All changes to the source code are reflected in the browser in real time! ⚡

## ✨ Features
- Responsive Design: A fully adaptive interface that looks and functions perfectly on everything from desktop monitors to tablets and mobile devices. 📱💻

- Interactive Filtering & Sorting: Intuitive search, filtering by brand/specifications, and product sorting to help you quickly find the model you're looking for. 🔍

- Shopping Cart & Wishlist: Add items to your cart, manage quantities, and save your favorite gadgets. 🛒❤️

- Modern Architecture: Built using React’s component-based architecture, hooks, and contemporary state management practices. ⚛️

- Modern Aesthetics: A stylish design featuring smooth animations and a high-performance interface. 🎨
